# Aura Mirage

**Files and text for listening** — notas, documentos e leitura em voz alta em português, com acesso rápido pela notificação.

## Escopo implementado neste lote

- notas locais com edição, salvamento, revisão e exclusão lógica;
- modelo local para notas, pastas, documentos e revisões;
- colagem de texto;
- leitura com `TextToSpeech` e voz `pt-BR` disponível no aparelho;
- notificação compacta com ações nomeadas;
- build e testes Android no GitHub Actions.

A base é local-first: não há login, nuvem ou leitura automática das notificações de outros aplicativos.
